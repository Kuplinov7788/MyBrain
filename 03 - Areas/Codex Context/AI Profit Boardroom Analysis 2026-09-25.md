# AI Profit Boardroom va Hermes Agent Revenue Kit

## Qisqa xulosa

AI Profit Boardroom — Julian Goldie yuritadigan, Skool’dagi pullik AI biznes hamjamiyati. U Hermes Agent dasturining o‘zi emas. Boardroom Hermes ustiga biznes workflow, shablon, Agent OS va mijoz topish/sotish bo‘yicha o‘quv materiallarini taklif qiladi.

## Sahifa nimalarni taklif qiladi

- Sahifani tekshirgan kuni: private guruh, 3.4k a’zo, 4.9 reyting/102 review, $69 oyiga.
- Ro‘yxatda: Agent OS Profit System, Hermes Agent Revenue Kit, Claude Profit Kit, Julian bilan Q&A, support, custom automation, haftasiga 4 ta live coaching call va giveaway’lar.
- Reklamadagi foydalanish misollari: lead generation, AI avatar content, avtomatizatsiyani xizmat sifatida qadoqlab sotish.
- Bular sotuv sahifasidagi taklif va da’volar; natijalar mustaqil audit bilan tasdiqlangani bu tekshiruvdan ma’lum emas.

## Hermes dasturi va pullik kit farqi

- Nous Research’ning [Hermes Agent GitHub repozitoriyasi](https://github.com/NousResearch/hermes-agent) — MIT litsenziyali open-source agent. Model/provider, tool, gateway, xotira va skills bilan ishlash uchun dasturiy runtime beradi.
- Julian Goldie’ning [Hermes Agent Revenue Kit tavsifi](https://juliangoldie.com/hermes-agent-revenue-kit/) bo‘yicha, kit — Agent OS, tayyor workflow/template va kontent, lead generation, productized service hamda mijoz topish bo‘yicha playbook/treninglar to‘plami. Bu tarifni sotuvchining o‘zi bergan; kitning to‘liq tarkibini faqat ommaviy sahifadan mustaqil tekshirib bo‘lmadi.
- [xulosa] Hermes’ni o‘rnatish yoki ishlatish uchun Boardroom obunasi shart emas. Obuna asosan shu community’ning biznes materiallari, coaching va supportiga kirish beradi.

## GitHub’da topilgan Agent OS repo’lar

- AI Profit Boardroom yoki `Hermes Agent Revenue Kit` nomli alohida rasmiy ochiq repo qidiruvda chiqmadi. Eng mos public candidate — [nilhemdot/agent-os](https://github.com/nilhemdot/agent-os): Agent OS dashboard/member pack. README’da dashboard lokal Hermes/Claude/OpenClaw CLI’larini, Obsidian journal/memory’ni, voice, goals va ko‘p agent tablarini birlashtirishi aytilgan.
- `nilhemdot/agent-os` README pack versiyasini `2026-07-03` deb ko‘rsatadi va eng yangi pack Boardroom ichida bo‘lishi mumkinligini aytadi. Repo public, lekin muallifning Julian Goldie yoki Boardroom ekanini GitHub sahifasidan tasdiqlay olmadim; shu sabab uni rasmiy upstream deb belgilamayman.
- [gdotbat/Hermes-agentic-os](https://github.com/gdotbat/Hermes-agentic-os) — ayni dashboardning public fork nusxasi. README uni Julian Goldie AIPB a’zolari uchun qurganini aytadi, ammo GitHub fork manbasi `quoctuancqt/agentic-os`; README esa kanonik clone manzili sifatida `JulianGoldie/agentic-os.git`ni ko‘rsatib, collaborator access kerakligini yozadi. README foydalanish shartlari “AIPB members only”, redistribution va resale’ga yo‘l qo‘ymaydi.
- [xulosa] Boardroom’dagi Agent OS — dashboard va biznes playbook qatlamiga o‘xshaydi; NousResearch Hermes esa agent runtime. Bu dashboard mavjud lokal Hermes CLI’ni ulab ishlatishi mumkin, ammo repo’ni klonlab yoki ishga tushirib xavfsizlik/compatibility tekshiruvini bajarmadim.

## Kimga foydali bo‘lishi mumkin

Freelancer, agentlik yoki kichik biznes egasi aniq bir AI workflow’ni mijozga xizmat qilib sotmoqchi bo‘lsa va muntazam coaching/support’dan foydalansa, mos kelishi mumkin. Faqat Hermes’ni sinash, mahalliy AI agent qurish yoki Beluga kabi shaxsiy avtomatizatsiyani ishlatish maqsadi bo‘lsa, pullik guruh zarur emas.

Julian’ning alohida [bepul AI Money Lab guruhi](https://www.skool.com/ai-seo-with-julian-goldie-1553/about) ham bor. Uning public sahifasi bepul kurslar, AI tools, promptlar va n8n workflow’larni sanaydi; uslub va materialni pul to‘lashdan oldin baholash uchun xavfi kamroq boshlanish nuqtasi.
